
# THE SECURITY ENGINE

This project demonstrates secure encryption and decryption of personal information using Node.js for the backend.

## Setup and Running Instructions

To get this project up and running on your local machine, please follow these steps:
 
1.  **Start the Server:**
    From the project's root directory, start the Node.js server:
    ```bash
    node server.js
    ```
    You should see a message in your terminal indicating the server is running (e.g., "Server running http://localhost:3000").

2.  **Access the Website:**
    Open your web browser and go to:
    ```
    http://localhost:3000 
    ```

## Functionality Overview

* **Encryption:** On the homepage, enter personal information into the provided form. When you submit, the data will be sent to the Node.js server and then the information would be encrypted into both alphanumeric digit and punctuation marks.


* **Decryption:** There will be a separate section(validation page) to decrypt the encrypted code into the information, demonstrating the data being returned to its original, readable format.
